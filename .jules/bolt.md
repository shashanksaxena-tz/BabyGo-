## 2024-05-18 - [Add `.lean()` to Mongoose read queries]
**Learning:** Performance Pattern: Use `.lean()` on Mongoose `.find()` queries for read-only operations to bypass document hydration, improving performance and memory usage. This eliminates the need for subsequent `.toObject()` calls on the results. However, be cautious not to use it when the code relies on Mongoose virtual fields (e.g., `displayAge` on the `Child` model, `totalReadingTimeSeconds` on the `Story` model) or document methods.
**Action:** Always check if a query result is only read and serialized to JSON. If so, and no virtuals are needed, apply `.lean()`. Always ensure to remove redundant `.toObject()` calls in subsequent mapping or processing loops. `.lean()` returns Plain Old JavaScript Objects (POJOs), which will cause `TypeError: d.toObject is not a function` if called.
