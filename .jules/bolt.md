## 2024-05-24 - Mongoose Read-Only Queries and document.toObject() overhead
**Learning:** Read-only operations with Mongoose (like listing all doctors or returning recommendations in `backend/src/routes/doctors.js`) generate significant overhead because Mongoose hydrates raw MongoDB documents into full JavaScript class instances (`mongoose.Document`). In some cases, to return the JSON result, code was explicitly calling `.toObject()` on retrieved items inside loops. This creates an N+1 performance bottleneck during hydration.
**Action:** Always append `.lean()` to Mongoose `.find()` or `.findOne()` queries that are read-only and whose returned objects are directly serialized or modified for API responses. This bypasses hydration, returns plain JS objects, saves memory, and avoids needing manual `.toObject()` calls in map or loop operations. Be careful not to use `.lean()` if virtuals or document methods are needed.
