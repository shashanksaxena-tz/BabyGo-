## 2024-06-23 - Use exists() instead of findOne() for simple existence checks
**Learning:** When validating the existence of a parent document before querying related records (e.g., verifying a Child exists before fetching TimelineEntries or similar operations), using `Model.exists()` instead of `Model.findOne()` saves memory and parsing time. `findOne()` hydrates a full Mongoose document, which is unnecessary if we only need to verify the record exists. We can also parallelize this existence check with the related data queries using `Promise.all()` to eliminate sequential blocking and reduce endpoint latency.
**Action:** Replace `Child.findOne({ _id: childId })` with `Child.exists({ _id: childId })` when the document data isn't used, and use `Promise.all` to fetch the child existence check and related records in parallel.
