## Quick Start

### Prerequisites
- Docker & Docker Compose installed
- Node.js 18+ (for running seed scripts manually)
- MongoDB client tools (optional, `mongosh` for direct DB access)

### Launch the Full Stack

```bash
# Navigate to project root
cd BabyGo-

# Start all services (Backend, MongoDB, MinIO, Web, Desktop frontends)
docker-compose up -d --build

# Verify services are running
docker-compose ps

# View backend logs
docker-compose logs -f backend
```

### Access Points
- **Backend API**: http://localhost:3001
- **Web App**: http://localhost:3005
- **Desktop App**: http://localhost:5173
- **MongoDB**: localhost:27017 (internal, no UI)
- **MinIO Console**: http://localhost:9001
- **MinIO API**: http://localhost:9000

### Admin/Developer Access

Currently, there is **no admin panel**. Instead, use:

1. **Direct MongoDB Access** (for data inspection/debugging)
   ```bash
   # Connect to MongoDB from host machine
   mongosh "mongodb://localhost:27017/tinysteps"
   
   # View users
   db.users.find().pretty()
   
   # View children
   db.children.find().pretty()
   
   # View login attempts (if logging enabled)
   db.logins.find().pretty()
   ```

2. **Backend API Direct Calls** (with JWT token)
   ```bash
   # Register a new user
   curl -X POST http://localhost:3001/api/auth/register \
     -H "Content-Type: application/json" \
     -d '{
       "email": "test@example.com",
       "password": "SecurePass123!",
       "name": "Test User"
     }'
   
   # Response contains JWT token - use it for authenticated requests
   # {
   #   "token": "eyJhbGciOiJIUzI1NiIs...",
   #   "userId": "user-uuid",
   #   "email": "test@example.com"
   # }
   
   # Login to get token
   curl -X POST http://localhost:3001/api/auth/login \
     -H "Content-Type: application/json" \
     -d '{
       "email": "test@example.com",
       "password": "SecurePass123!"
     }'
   ```

## Database Setup

### MongoDB

MongoDB stores all application data (users, children, analyses, milestones, etc.).

#### Connection String
```
MongoDB URI (for Docker): mongodb://mongo:27017/tinysteps
MongoDB URI (local dev):  mongodb://localhost:27017/tinysteps
```

#### Environment Variables
```env
# .env or docker-compose.yml
MONGODB_URI=mongodb://mongo:27017/tinysteps
```

#### Collections Created Automatically
When the backend starts, these collections are created:

| Collection | Purpose |
|-----------|---------|
| `users` | Parent accounts (email, password hash, JWT tokens) |
| `children` | Child profiles (DOB, gender, measurements, achieved milestones) |
| `analyses` | Development analyses (milestones at specific dates) |
| `stories` | Bedtime stories generated by Gemini AI |
| `milestones` | Development milestones (WHO data) - seeded by migrations |
| `recipes` | Age-appropriate recipes - seeded by migrations |
| `tips` | Parenting tips - seeded by migrations |
| `products` | Baby care products - seeded by migrations |
| `activities` | Age-based activities - seeded by migrations |
| `doctors` | Pediatrician directory - seeded by migrations |
| `timelineentries` | User activities (analyses, measurements, notes, photos) |
| `communitypost` | Community discussion posts |
| `communities` | Community groups |
| `migrations` | Migration tracking (which scripts have run) |

#### Verify Connection

```bash
# Using mongosh (interactive shell)
mongosh "mongodb://localhost:27017/tinysteps"

# Inside MongoDB shell:
db.adminCommand('ping')  # Should return { ok: 1 }

# Count collections
db.getCollectionNames()

# Check document counts
db.users.countDocuments()
db.children.countDocuments()
db.milestones.countDocuments()
```

### MinIO (Object Storage)

MinIO is an S3-compatible object storage service for storing binary files:
- Profile photos
- Story illustrations (generated by Gemini)
- Report PDFs

#### Connection Details

**MinIO Console** (Web UI)
- URL: http://localhost:9001
- Access Key: `minioadmin`
- Secret Key: `minioadmin`

**MinIO API** (S3-compatible)
- Endpoint: `localhost:9000`
- Public URL (for browser access): `http://localhost:9000`

#### Environment Variables

```env
# Docker Compose sets these automatically
MINIO_ENDPOINT=minio                    # Internal hostname (Docker)
MINIO_PORT=9000
MINIO_ACCESS_KEY=minioadmin            # Default credentials
MINIO_SECRET_KEY=minioadmin
MINIO_USE_SSL=false
MINIO_PUBLIC_URL=http://localhost:9000 # Browser-accessible URL
```

#### Buckets (Auto-Created)

When backend starts, these buckets are created automatically:

| Bucket | Purpose | Public Access |
|--------|---------|---------------|
| `profile-photos` | Child profile pictures | Read-only URL |
| `story-illustrations` | AI-generated story images | Read-only URL |
| `report-pdfs` | Generated development reports | Read-only URL |

#### Access MinIO Console

1. Open http://localhost:9001
2. Login with:
   - Username: `minioadmin`
   - Password: `minioadmin`
3. Browse buckets and uploaded files
4. Generate presigned URLs for sharing

## Working with MongoDB

### Connect from Your Machine

```bash
# Using mongosh (MongoDB Shell)
mongosh "mongodb://localhost:27017/tinysteps"

# Inside shell, useful commands:
show databases              # List all databases
use tinysteps              # Switch to tinysteps DB
show collections           # List all collections
db.users.find().pretty()   # View users (formatted)
db.children.find().limit(5).pretty()  # View first 5 children
```

### Common Database Operations

#### Query Users
```bash
# Find user by email
db.users.findOne({ email: "priya@tinysteps.dev" })

# Find all users
db.users.find().pretty()

# Count users
db.users.countDocuments()
```

#### Query Children & Milestones
```bash
# Find children for a specific parent
db.children.find({ parentId: "uuid-here" }).pretty()

# Find milestones for specific domain
db.milestones.find({ domain: "motor" }).pretty()

# Get milestone stats
db.milestones.aggregate([
  { $group: { _id: "$domain", count: { $sum: 1 } } }
]).pretty()
```

#### Query Timeline (Activities)
```bash
# View timeline entries for a child
db.timelineentries.find({ childId: "uuid-here" }).sort({ date: -1 }).pretty()

# Count by type
db.timelineentries.aggregate([
  { $group: { _id: "$type", count: { $sum: 1 } } }
]).pretty()
```

#### Query Analyses
```bash
# View analyses for a child
db.analyses.find({ childId: "uuid-here" }).pretty()

# Get average scores by domain
db.analyses.aggregate([
  { $group: { _id: "$domain", avgScore: { $avg: "$score" } } }
]).pretty()
```

### Backup & Export Data

```bash
# Backup entire MongoDB
mongodump --uri="mongodb://localhost:27017/tinysteps" --out=./backup/

# Export specific collection to JSON
mongoexport --uri="mongodb://localhost:27017/tinysteps" \
  --collection=children \
  --out=children.json

# Import data back
mongoimport --uri="mongodb://localhost:27017/tinysteps" \
  --collection=children \
  --file=children.json
```

### Reset/Clean Database

```bash
# WARNING: Deletes all data!
mongosh "mongodb://localhost:27017/tinysteps"

# Inside mongosh:
db.dropDatabase()  # Remove all collections

# Or specific collections:
db.users.deleteMany({})
db.children.deleteMany({})
db.analyses.deleteMany({})

# Migrations will re-seed on next backend start
```

## Working with MinIO

### Access MinIO Console

1. **Open Browser**: http://localhost:9001
2. **Login**: 
   - Username: `minioadmin`
   - Password: `minioadmin`
3. **Browse**: Click on bucket names to see files

### Using MinIO CLI (mc)

```bash
# Install MinIO CLI (if not in Docker)
brew install minio/stable/mc  # macOS
# or download from https://min.io/download

# Configure alias (one-time)
mc alias set local http://localhost:9000 minioadmin minioadmin

# List buckets
mc ls local

# List files in bucket
mc ls local/profile-photos
mc ls local/story-illustrations
mc ls local/report-pdfs

# Upload a file
mc cp ./image.jpg local/profile-photos/

# Download a file
mc cp local/profile-photos/image.jpg ./

# Set public policy (read-only access)
mc policy set download local/profile-photos
```

### Direct API Calls

```bash
# Generate presigned URL for a file (valid for 1 hour)
# This allows temporary public access without needing AWS credentials

curl -X POST http://localhost:9000 \
  -H "Authorization: AWS4-HMAC-SHA256 ..." \
  # (Complex signature; use SDK instead)
```

### Using Node.js SDK

The backend uses `minio` npm package:

```javascript
// Example: Upload file to MinIO
import { Client as MinioClient } from 'minio';

const client = new MinioClient({
  endPoint: 'localhost',
  port: 9000,
  useSSL: false,
  accessKey: 'minioadmin',
  secretKey: 'minioadmin',
});

// Upload a file
await client.fPutObject('profile-photos', 'child-123.jpg', './photo.jpg');

// Generate presigned URL (valid for 1 hour)
const url = await client.presignedGetObject('profile-photos', 'child-123.jpg', 3600);
console.log('Access URL:', url);

// Download a file
await client.fGetObject('profile-photos', 'child-123.jpg', './downloaded.jpg');

// Delete a file
await client.removeObject('profile-photos', 'child-123.jpg');
```

### Verify Buckets Are Created

```bash
# Via console: http://localhost:9001 > see bucket names on left

# Via CLI:
mc ls local

# Via API check in backend logs:
docker-compose logs backend | grep "Buckets ready"
```

## Troubleshooting

### Services Not Starting

```bash
# Check if ports are in use
lsof -i :3001  # Backend
lsof -i :27017  # MongoDB
lsof -i :9000  # MinIO API
lsof -i :9001  # MinIO Console

# Kill process using port (if needed)
kill -9 <PID>

# Restart services
docker-compose restart
docker-compose up -d
```

### MongoDB Connection Issues

```bash
# Verify MongoDB is running
docker-compose logs mongo

# Check health
docker-compose exec mongo mongosh --eval "db.adminCommand('ping')"

# Reset MongoDB
docker-compose down
docker volume rm babygodockercompose_mongo_data
docker-compose up -d mongo
```

### MinIO Connection Issues

```bash
# Verify MinIO is running
docker-compose logs minio

# Check health
docker-compose exec minio mc ready local

# Access console
# http://localhost:9001
# Username: minioadmin
# Password: minioadmin

# Reset MinIO
docker-compose down
docker volume rm babygodockercompose_minio_data
docker-compose up -d minio
```

### Seed Script Failures

```bash
# Check backend is running
curl http://localhost:3001/health

# Verify database connection
mongosh "mongodb://localhost:27017/tinysteps"

# Run seed with verbose output
cd backend
NODE_DEBUG=* npm run seed:realistic

# Check for JWT token expiry (if seed takes too long)
# Can happen if Gemini API is slow
# Solution: Run in smaller batches or increase timeout
```

### Migration Issues

```bash
# Check migration status
docker-compose exec -T mongo mongosh "mongodb://localhost:27017/tinysteps" \
  --eval "db.migrations.find().pretty()"

# Reset migrations (clears tracking, will re-run all)
docker-compose exec -T mongo mongosh "mongodb://localhost:27017/tinysteps" \
  --eval "db.migrations.deleteMany({})"

# Re-run backend to execute migrations again
docker-compose restart backend
```

### File Upload Issues

```bash
# Verify bucket exists
docker-compose exec minio mc ls local

# Check bucket policies
docker-compose exec minio mc policy get local/profile-photos

# Fix permissions if needed
docker-compose exec minio mc policy set download local/profile-photos
docker-compose exec minio mc policy set download local/story-illustrations
docker-compose exec minio mc policy set download local/report-pdfs
```
